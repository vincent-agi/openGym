# Architecture decision records

Short records of decisions that are hard to reverse, surprising without context, and the result of a real trade-off. The format is
deliberately light: a few sentences, plus *Considered options* and *Consequences* when they earn their place. Files are numbered
`NNNN-slug.md`, and the `status` in the frontmatter is `proposed`, `accepted`, `deprecated` or `superseded by ADR-NNNN`.

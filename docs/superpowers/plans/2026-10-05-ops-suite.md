# Ops suite (sub-project 3) — implementation plan

Spec §5. Same method as the previous sub-projects: TDD, bash 3.2, `shellcheck -S warning`, mocks, commands in `scripts/ops/`.

## Task 1 — Shared building blocks
- `common.sh`: `run_with_timeout <secs> cmd…` (portable, no `timeout` on macOS).
- `lib/archive.sh`: `archive_open` = decrypt + checksum + safe-path/type check + extract aside + JSON validation, extracted from `restore`
  (which now uses it, its tests are the safety net). Reused by `verify --backup`.
- `lib/checks.sh`: check framework (`report OK|WARN|FAIL id message [hint]`, level, text/JSON rendering) and the shared checks used by
  `doctor` and `monitor`: docker, containers, front door, API health, data dir, db.json, secret/vapid perms, `.env` consistency
  (+ API startup line), media, stray `*.tmp`, state sizes, disk, backup age, TLS expiry.

## Task 2 — `doctor`
All shared checks with fix hints mapped to the troubleshooting table of operations.md. `--json`. Exit 0 / 10 / 20.

## Task 3 — `monitor`
Shared checks + user-count drop (high-water mark, `--accept-users`), restart-count increase, push-failure spike. Silent when healthy;
alerts per check key with cooldown and recovery notices. Exit 0 / 10 / 20.

## Task 4 — `verify`
Read-only integrity: JSON validity, creds/subs/invites ↔ users, duplicate ids, orphan state files; `--backup ARCHIVE` verifies an archive
without touching `data/`. `--json`.

## Task 5 — `prune`
Stale `*.tmp`, log rotation, expired backups, old `data.broken.*`/`data.bak.*` (asks), optional dangling images. Report-only without a TTY
unless `--yes`. `--dry-run`.

## Task 6 — `rotate-keys session|vapid`
Mandatory backup, impact warning, confirmation, delete + restart API, verify the new key file and health.

## Task 7 — `rollback`
Pins image tags with a generated `docker-compose.override.yml` (marker-protected), `--clear`, `--with-data ARCHIVE`; `update` refuses to
run silently over a pin.

## Task 8 — `schedule install|remove|show`
User crontab block with markers (backup daily, monitor every N min, report if present), `--system` for `/etc/cron.d`, systemd units text.

## Task 9 — Docs and wrap-up
`automation.md` reference, `operations.md` table, spec notes, full runs on bash 3.2 and 5, shellcheck, `help --check`.

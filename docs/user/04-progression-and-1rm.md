# 4. Progression and 1RM

## Progression: Gymme suggests your next weight

Getting stronger means doing a little more over time. Gymme can work out the next target for you, so **the
weight is already right when you open the workout**. Every target comes with a short explanation of *why*
it is that number.

Choose a rule for a whole routine (in the routine screen) or for one exercise (in the exercise settings →
**Progression → Rule**). An exercise rule beats the routine rule. If you pick nothing, reps exercises use
**Linear progression**.

### The rules

| Rule | How it works | Good for |
|---|---|---|
| **No automatic progression** | Targets stay where you set them. | You want full control. |
| **Linear progression** | Do every rep of every set and the weight goes up by one step next time. After repeated misses, the weight is reduced (a *deload*). | Most lifts, most people. |
| **Greyskull LP** | Two normal sets, then a last set taken to failure (as many reps as you can). Beat the target on that last set and the weight goes up — twice as much if you doubled the reps. One failure resets the weight by 10%. | Beginners following the Greyskull programme. |
| **Double progression** | Work up through a rep range (for example 8–12) at the same weight. Reach the top of the range in every set and the weight goes up while reps return to the bottom. | Muscle building, machines, dumbbells. |
| **Add time** | Hold every set for the full time and the target time goes up. | Planks and holds. |

### Good to know

- **Missed reps never move the weight up.** A set you did not tick, or finished with fewer reps than the
  target, counts as a miss.
- **A stall triggers a deload.** After several sessions in a row with misses, Gymme lowers the weight by about
  10% (Greyskull does it after the first failure). It rounds to a weight you can really load.
- **Step size.** Lower-body and back exercises jump by 5 kg (10 lb) by default; others by 2.5 kg (5 lb).
  You can set your own step per exercise.
- **Bodyweight exercises grow in reps**, not weight. If you set a **top of the range**, Gymme adds a *set*
  when you reach it instead of another rep, up to 6 sets. After that the honest advice is "add weight or
  find a harder variation".
- **Old workouts are read fairly.** Your suggestion is worked out from your history each time, so if you fix a
  mistyped set, the next target fixes itself.

## Estimated 1RM

Your **1RM** ("one-rep max") is the heaviest weight you could lift one time. Most people never test it,
because it is hard and risky. Gymme estimates it from your normal sets with the **Epley formula**:

```
estimated 1RM = weight × (1 + reps ÷ 30)
```

For example, 80 kg for 5 reps gives about 93 kg.

- It uses your **best set** and tells you which set it was.
- It will **not guess above 12 reps**. Beyond that an estimate is too unreliable.
- One rep at a weight is shown as that weight — a measurement, not an estimate.
- It is an **estimate, not a tested max**. Use it to see the trend, not to decide a heavy single.

Where to find it:

- **Exercise detail** (tap the info icon on any exercise) has a **1RM calculator** for sets you have not done.
- **Stats → Exercise progress** can show **Estimated 1RM per workout** as a curve.
- A finished workout can show **Best estimated 1RM** when you did more reps at the same weight.

## Effort is separate

The RIR/RPE column (see [Working out](03-workouts.md#how-hard-was-the-set-rir-and-rpe)) is only a note about how it felt.
It does not change what Gymme suggests next.
